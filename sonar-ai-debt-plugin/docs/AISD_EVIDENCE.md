# AISD evidence and rule provenance

Production AISD findings use the source catalogue identifiers `SPECDETECT4AI-R1` through `SPECDETECT4AI-R24`, with `R11bis` retained as the second R11 leakage detector. The authoritative catalogue and integration contract are documented in [SpecDetect4AI integration](SPECDETECT4AI.md).

The older `AIDEBT-PY-xxx` identifiers are plugin-defined diagnostics. They are not SonarSource, CWE, or paper identifiers and are no longer counted in AISD.

## Supplemental evidence outside AISD

Zhang et al. studied 311 Python files identified as GitHub Copilot-generated and manually confirmed 102 smell instances. Eight Python smell families were observed: Multiply-Nested Container, Long Parameter List, Long Method, Long Lambda Function, Long Ternary Conditional Expression, Complex Container Comprehension, Long Message Chain, and Large Class. These remain useful supplemental diagnostics but are not mixed into the SpecDetect4AI AISD numerator. Source: [Copilot-in-the-Loop](https://arxiv.org/abs/2401.14176).

Security studies show that AI-generated code can contain security weaknesses. Hard-coded credentials, unsafe dynamic evaluation, and missing randomness controls remain useful review signals but are not uniquely AI smells and are not added to the AISD numerator unless represented by a SpecDetect4AI rule. Sources: [Asleep at the Keyboard?](https://arxiv.org/abs/2108.09293), [Security Weaknesses of Copilot-Generated Code](https://arxiv.org/abs/2310.02059).

Context switches, redundant logic, semantic/name inconsistency, and explanation gaps belong to CogDI and are always excluded from AISD.

## Interpretation boundary

A SpecDetect4AI finding means that a static approximation matched a declared rule. It does not prove a runtime defect and does not prove that code was generated by AI. Thesis validation must report rule-level precision/recall, Human/AI prevalence, effect size, and sensitivity to detector assumptions. Rules that fail validation should be removed or reclassified before confirmatory analysis.

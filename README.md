# Sonar AI Debt Plugin for Python

This private research repository contains a Python-only SonarQube plugin for
measuring technical and cognitive debt signals in code associated with
AI-assisted software development.

## Repository contents

- [`sonar-ai-debt-plugin/`](sonar-ai-debt-plugin/) — the Java 17 SonarQube
  plugin, dashboard, Python metric engine, automated tests, and research
  documentation.
- [`SpecDetect4AI-B903/`](SpecDetect4AI-B903/) — the authorized SpecDetect4AI
  snapshot used to generate the R1–R24 JSON evidence consumed by AISD.

The two directories intentionally remain siblings because the reproducible detector
and plugin commands use this layout.

## Start here

Read the
[`Research Artifact documentation`](sonar-ai-debt-plugin/docs/RESEARCH_ARTIFACT.md)
for prerequisites, dependency installation, plugin deployment, detector execution,
SonarScanner analysis, output export, validation, and reuse instructions.

For a quick build:

```bash
cd sonar-ai-debt-plugin
mvn clean verify
```

For the complete end-to-end workflow, including SpecDetect4AI and SonarQube,
follow the research artifact document rather than running components in isolation.

## Scope

The analyzer supports Python `.py` main-source files only. Java is the
implementation language of the SonarQube plugin and JavaScript is used only to
render its dashboard; neither Java nor JavaScript source code is analyzed.

The plugin reports predefined debt signals. It does not prove that code was
generated by AI. Source provenance belongs to the study design and remains
external to the metric engine.
